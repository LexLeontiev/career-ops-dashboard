# Support

For usage questions, use GitHub Discussions when it is enabled for this repository. For reproducible defects, open the [bug report form](.github/ISSUE_TEMPLATE/bug.yml) with synthetic data only. For feature ideas, use the [feature request form](.github/ISSUE_TEMPLATE/feature.yml).

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
