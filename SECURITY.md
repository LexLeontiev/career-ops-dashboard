# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1   | No        |

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub private vulnerability reporting when available, or email lexleontiev@gmail.com.

Please include a concise description, affected version, reproduction steps that use synthetic data only, impact, and any suggested mitigation. Do not include real career data, credentials, or private paths.
