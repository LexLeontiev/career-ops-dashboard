# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-14

### Added

- A local-first dashboard for browsing career-ops application tracker data and read-only Markdown reports.
- Local integration with the canonical career-ops checkout through its tracker parser adapter.
- Privacy mode, local-only defaults, and a localhost server bind.
- Accessible dashboard controls, table sorting, filtering, and report drawer behavior.
- Automated tests, release quality checks, and GitHub Actions coverage for Node 22 and 24 on macOS and Linux.
- Contributor, support, security, architecture, release, and community documentation.
